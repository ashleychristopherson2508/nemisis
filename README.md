# Nemesis Eye

An interactive motion-responsive eye Progressive Web App.

## Live App

[Open Nemesis Eye](https://ashleychristopherson2508.github.io/nemisis/)

## Features

- Installable PWA for phones, tablets, and laptops
- Offline app shell through a service worker
- Camera-based motion detection
- Responsive fullscreen display

Camera access requires HTTPS and permission from the browser.
